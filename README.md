## 📌 Sobre o projeto

O **ÁgilCert** consiste no desenvolvimento de um portal de aprendizagem e certificação em metodologias ágeis, com foco nos conceitos e práticas do Scrum, desenvolvido como projeto da faculdade.

A plataforma permite que os usuários acessem conteúdos educacionais, acompanhem seu progresso nos estudos e realizem uma avaliação para obter sua certificação.

O projeto busca proporcionar uma experiência intuitiva, acessível e responsiva, reunindo aprendizado e avaliação em um único ambiente.

---

## 🎯 Objetivos

Desenvolver uma plataforma que permita:

- Apresentar conteúdos sobre metodologias ágeis e Scrum;
- Disponibilizar materiais de estudo organizados por temas;
- Permitir cadastro e autenticação de usuários;
- Registrar e acompanhar o progresso individual;
- Disponibilizar avaliações de fixação;
- Realizar uma prova de certificação;
- Emitir certificados conforme os critérios de aprovação estabelecidos.

## 🛠️ Tecnologias utilizadas

O projeto utiliza as seguintes tecnologias e ferramentas:

## 💻 Executar o projeto completo localmente

Para executar o ambiente completo, é necessário ter o **Node.js 22** ou superior e o **Docker Desktop** aberto.

Na raiz do projeto, execute:

```bash
node scripts/preparar-compose.mjs
docker compose --env-file .env.compose up --build -d
```

Acesse <http://localhost:3000>. O comando de preparação cria as credenciais locais em `.env.compose`.

Para executar sem Docker e configurar o backend, consulte [Funcionalidades e operação](docs/sprint-3/FUNCIONALIDADES_E_OPERACAO.md).

Para executar os testes disponíveis sem banco real:

```bash
cd backend
npm ci
npm test
```

Os testes de integração PostgreSQL dependem de `SECURITY_TEST_CONTAINER` e ficam ignorados sem essa configuração.

### Certificado e validação

O certificado pode ser aberto pelo resultado ou histórico. O botão **Baixar certificado** abre a impressão do navegador; selecione **Salvar como PDF**.

O QR Code usa a origem do site por padrão. Para um endereço diferente, configure `AGILCERT_PUBLIC_BASE_URL` em `frontend/src/assets/js/config.js`. O endereço deve ser acessível pelo aparelho que fará a leitura; `localhost` não funciona em outro aparelho.

Consulte a [documentação da API](docs/Documentacao_API_AgilCert.md). A homologação final ainda exige evidências dos testes com banco real, leitura do QR Code em celular e aceite da equipe/PO.
