# Imagens das questões

Uma imagem para cada uma das 48 questões da carga (PB-054). O nome do arquivo é o
código da questão (`codigo_seed`), por exemplo `PB053-1-1.png` = tema 1, questão 1.

## Autoria e licença

- **Fonte:** ilustrações do [unDraw](https://undraw.co), escolhidas pela equipe e
  reunidas no documento "Cursos - ABP" (legendas "Fonte: unDraw (2026)").
- **Licença:** [licença unDraw](https://undraw.co/license): uso gratuito, inclusive
  comercial, sem necessidade de pedir permissão ou dar crédito.

## Como trocar ou adicionar uma imagem

1. Salve o arquivo em PNG nesta pasta com o código da questão.
2. Ajuste o `imagem_alt` da questão em `backend/scripts/data/content-estudos.json`.
3. Rode `npm run seed:gerar` na pasta `backend`.

Se a imagem não carregar, a página de estudos mostra "Imagem indisponível." no lugar.
