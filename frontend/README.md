# Frontend ÁgilCert

Estrutura criada em HTML, CSS e JavaScript puro.

## Arquivos
- `index.html` / `login.html`: tela de login
- `cadastro.html`: tela de cadastro
- `assets/css/main.css`: CSS global
- `assets/js/auth.js`: interações básicas
- `assets/img/`: logo e ilustração extraídas do material de padronização

## Executar
Abra `index.html` com Live Server ou sirva a pasta `frontend_agilcert` pelo backend Node.js.

Os formulários estão prontos visualmente e com validações básicas; as ações de login/cadastro ainda devem ser conectadas às rotas do backend.
