# Burndown — Sprint 3

**Período oficial:** 06/11/2026 a 25/11/2026  
**Escopo:** 18 PBIs  
**Resultado registrado no GitHub Projects:** 18 Issues com status `Done`

## Método

O burndown da Sprint 3 acompanha o trabalho relacionado à implementação e validação do fluxo de certificados da aplicação, considerando o escopo registrado no GitHub Projects.

Durante a Sprint 3, foi desenvolvida a funcionalidade de geração de certificados após a conclusão e aprovação do usuário na prova. O certificado possui um QR Code para validação pública. Ao escanear o código, o usuário é direcionado à página de validação, que recupera o token associado ao certificado e verifica sua autenticidade consultando o token armazenado no banco de dados.

A visualização do burndown representa a evolução das tarefas ao longo do período oficial da Sprint, de 06/11/2026 a 25/11/2026.
